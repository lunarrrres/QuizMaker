# QuizMaker — Головний план розробки

> **Для ШІ-агентів:** Перед початком роботи прочитай `PROGRESS.md`. Знайди перший крок зі статусом `[TODO]` або `[IN PROGRESS]` і почни з нього. Не пропускай кроки і не починай наступний до завершення поточного.

---

## Структура плану

| Файл | Зміст |
|------|-------|
| `README.md` | Цей файл — навігація по плану |
| `PROGRESS.md` | Журнал прогресу (оновлюється після кожного кроку) |
| `AGENT_INSTRUCTIONS.md` | Інструкції для ШІ-агентів як працювати з планом |
| `FILE_TREE.md` | Повне дерево файлів проєкту |
| `phases/PHASE-0.md` | Фаза 0 — Підготовка середовища |
| `phases/PHASE-1.md` | Фаза 1 — Авторизація |
| `phases/PHASE-2.md` | Фаза 2 — Редактор квізів |
| `phases/PHASE-3.md` | Фаза 3 — Режим гри Jeopardy |
| `phases/PHASE-4.md` | Фаза 4 — Полірування |
| `schemas/MONGOOSE_SCHEMAS.md` | Mongoose-схеми для всіх моделей |
| `schemas/API_CONTRACTS.md` | REST API ендпоінти та контракти |
| `schemas/JOTAI_STATE.md` | Jotai atoms та структура стану гри |

---

## Короткий огляд фаз

```
PHASE-0  Підготовка середовища        ~2-3 год   [монорепо, Vite, NestJS, MongoDB]
PHASE-1  Авторизація                  ~3-4 год   [register, login, JWT, guards]
PHASE-2  Редактор квізів              ~5-7 год   [CRUD квізів, UI сітки]
PHASE-3  Режим гри Jeopardy           ~6-8 год   [ігровий екран, бали, таймер]
PHASE-4  Полірування                  ~3-4 год   [анімації, edge cases, тести]
```

---

## Технічний стек

### Frontend
- **Runtime/Build:** Vite + React + TypeScript
- **Стилі:** TailwindCSS
- **Компоненти:** shadcn/ui
- **Глобальний стан:** Jotai
- **Серверний стан:** TanStack Query v5

### Backend
- **Runtime:** Bun
- **Фреймворк:** NestJS
- **ODM:** Mongoose
- **БД:** MongoDB (Docker)
- **Авт:** JWT (access + refresh tokens)

## Принципи роботи з планом

1. **Атомарність** — кожен крок робить одну конкретну річ
2. **Перевірюваність** — кожен крок має чіткий критерій завершення
3. **Послідовність** — не починай крок, якщо не виконані його залежності
4. **Фіксація** — після кожного кроку оновлюй `PROGRESS.md`
